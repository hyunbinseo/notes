## Bottles

Browse `C:/` drive 버튼 사용해서 맑은고딕 폰트 파일 추가할 것:

```plaintext
/drive_c/windows/Fonts/malgun.ttf
```

### PC 카카오톡

Bottles v67.0 기준:

- Bottle 실행기: Built-in Wine 11.0
- Xwayland(기본값)에서 터치패드 두 손가락 스크롤이 작동함
- Screen Scaling 값을 165로 설정해도 '시스템 기본 배율 (150%)'로 표시되고 적용됨
